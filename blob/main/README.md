# 🌿 Paradise Nursery - Shopping Cart Application

## Project Overview
Paradise Nursery is a dynamic e-commerce web application built with React and Redux that allows users to browse and purchase houseplants. The application features a responsive design with a shopping cart system, category-based product browsing, and real-time cart management.

## Features
- **Landing Page**: Beautiful welcome page with "Get Started" button
- **Product Listing**: Browse plants organized by categories (Indoor, Outdoor, Succulents)
- **Shopping Cart**: Add/remove items, adjust quantities, and view total costs
- **Responsive Navigation**: Easy access to Home, Plants, and Cart pages
- **Redux State Management**: Efficient cart state handling

## Technologies Used
- React.js
- Redux Toolkit
- React Router DOM
- CSS3
- GitHub
